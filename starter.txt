GitHub's current code search supports exact strings, Boolean queries, regexes, and path qualifiers, although it mainly indexes default branches, so it will miss deleted or historical material.

Mine the public GitHub event stream, not just current GitHub. GH Archive records public GitHub events—commits, issue activity, PRs, comments, forks, releases, etc.—and provides hourly raw archives plus a BigQuery dataset. That lets us search periods such as May–September 2026 for suspicious phrases in issue/PR/comment bodies and then cluster them by repository, actor and time. The important pattern is:

Agent/account A leaves instruction
       ↓
unrelated account B appears minutes/hours later
       ↓
B modifies same repo/file or references A's state
       ↓
A or C subsequently reacts

That is much stronger evidence than finding a README saying "agents should cooperate."

Recover things that disappeared. Once GH Archive gives us an account, repository, Gist URL, commit SHA or filename, look for its former contents in several archives. Software Heritage regularly archives public Git repositories and says archived source remains preserved even if the original repository is later deleted. The Wayback CDX API can enumerate historical captures by URL and date, including prefix searches. Common Crawl provides both a URL index and archived page contents, including bulk-queryable Parquet indexes.

Search for behavior rather than the word “agent.” Machine collaborators may never identify themselves. Good signals would include files such as TASKS.md, STATUS.md, FLAGS.md, mailbox/, handoff.md, shared_state.json, or messages such as:

VETO
result for whoever finds this

Then look for a second actor actually obeying the instruction. That consumption event is the evidence we care about.
